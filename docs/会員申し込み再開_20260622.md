# 会員のマイページ申し込み再開（一口支援・寄付・見学・面会・特別チーム）

対応日：2026-06-22

## 背景（お客様からのお問い合わせ）

> 現在1口支援、リタポ、寄付、見学などが、申し込みできない状況となっております。至急お願いしたいです。

## 原因（不具合ではなく設定）

2026-06-17 にご要望で実装した「会員操作の管理者限定化」
（[会員操作の管理者限定化_20260617.md](会員操作の管理者限定化_20260617.md)）が有効になっていたためです。

- フィーチャーフラグ `NEXT_PUBLIC_MEMBER_SELF_SERVICE` が未設定（＝無効）のため、
  会員のマイページから **一口支援の追加・寄付・見学（予約）・馬の面会** の
  申し込みボタンを非表示にし、対応する API も拒否していました。
- 特別チーム会員（リタポ）の新規受付は、さらに別フラグ
  `NEXT_PUBLIC_SPECIAL_TEAM_SIGNUPS` でも停止していました。
- 公開ページの単発寄付（/donate・ログイン不要）のみ対象外で動作しますが、
  会員はマイページから操作できないため「寄付もできない」と認識されていました。

システムは設定どおりに動作しており、コードの不具合はありません。

## 対応（ご指示：すべて再開＝特別チーム含む）

以下2つのフラグを有効化します。

| 環境変数 | 値 | 効果 |
| --- | --- | --- |
| `NEXT_PUBLIC_MEMBER_SELF_SERVICE` | `true` | 一口支援の追加・寄付・見学(予約)・馬の面会の申し込みを再開 |
| `NEXT_PUBLIC_SPECIAL_TEAM_SIGNUPS` | `true` | 特別チーム会員（リタポ／馬ごと月額¥1,000）の新規受付を再開 |

ローカル（`.env.local`）には設定済みです。

## ★本番（Vercel）への反映手順 — これを行わないと本番は変わりません

`NEXT_PUBLIC_*` はビルド時に埋め込まれるため、**Vercel の環境変数を設定し、再デプロイ**する必要があります。

1. Vercel ダッシュボード → 対象プロジェクト → **Settings → Environment Variables**
2. 次の2件を **Production**（必要なら Preview/Development も）に追加：
   - `NEXT_PUBLIC_MEMBER_SELF_SERVICE` = `true`
   - `NEXT_PUBLIC_SPECIAL_TEAM_SIGNUPS` = `true`
3. **Deployments → 最新のデプロイ → Redeploy**（または新規 push で再デプロイ）
4. 反映後、会員でログインしマイページに以下が表示されることを確認：
   - 「+ 新しい支援を追加」ボタン
   - クイックアクションの「寄付する」「予約する」「馬の面会」
   - 特別チーム会員の「+ 申し込む」

## 元に戻す場合

各フラグを `false` にする（または削除する）と、再び運営代行の運用（管理者限定）に戻ります。

## 補足・確認事項

- 各申し込みフローは決済面でも安全に再開できることを確認済み
  （見学予約は決済非依存。寄付・一口支援は決済同期に失敗した場合も
  「手続き中(incomplete)」で保持し、二重課金や不整合が起きないようハンドリング済み）。
- 既知の「Stripe Webhook 未着」問題は本件とは別件です。会員が一口支援・会員種別を
  申し込んだ際、Webhook が届かないとステータス反映が遅れる可能性があるため、
  Webhook の到達確認も別途推奨します。
