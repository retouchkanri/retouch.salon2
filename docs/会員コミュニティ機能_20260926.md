# 会員専用コミュニティ（2026-09-26）

Retouch サイト内の会員専用コミュニティ（`/community`）です。Slack の1つのワークスペースと同じ使い方・見た目で、
公開チャンネル・非公開チャンネル・ダイレクトメッセージ・スレッドを利用できます。

## 導入・更新の手順

1. **データベースの更新**：Supabase ダッシュボード → SQL Editor に `supabase/community.sql` の全文を貼り付けて「Run」。
   - すでに適用済みでも、全文をもう一度実行すれば最新の状態になります（メッセージなどのデータは変わりません）。
   - 初期チャンネル（お知らせ／全体／馬の近況／イベント／運営スタッフ）と、会員種別ごとのチャンネル
     （メンバーズ会員／サポーター会員／リェリーフ会員／オーナーズ会員／ヘルパーズ会員／リタポメンバー／特別チーム会員）が、
     まだ無い場合だけ作成されます。
2. **デプロイ**：コードを本番に反映します（必ず 1 の後に行ってください）。
3. これで完了です。**「公開」の操作は不要**で、有効な会員はすぐにヘッダー・マイページから参加できます。

## 参加のしかた（Slack と同じ）

| チャンネル | 参加するメンバー |
| :-- | :-- |
| 全員参加の公開チャンネル（お知らせ・全体・馬の近況・イベント） | すべての会員が自動でメンバー（入会すると自動で追加） |
| 会員種別ごとのチャンネル（🔒） | その会員種別の方だけが自動でメンバー。契約の開始・終了に自動で追従し、ほかの会員には表示されません |
| 支援者チャンネル（🔒、管理画面の「馬ごとの支援者チャンネルを作成」） | その馬を支援中の方だけが自動でメンバー |
| 会員・運営が作成した公開チャンネル（#） | 「チャンネル一覧」から誰でも参加できます |
| 非公開チャンネル（🔒） | 招待されたメンバーのみ（運営は閲覧できます） |

- メンバー数はチャンネルのヘッダー・チャンネル一覧・チャンネルの詳細に表示されます（Slack と同じ）。
- 会員は、表示名を設定するとチャンネルを作成できます（1日5個・同時に30個まで。「運営」「公式」「お知らせ」などを含む名前は不可）。
  作成者はチャンネル名の変更、アーカイブ、非公開チャンネルのメンバーの削除、ピン留めができます。
- 運営は、画面内の「チャンネルを作成する」で「運営だけが投稿できる（お知らせ・イベント用）」「全員を自動で参加させる」も選べます。
  対象者（会員種別・支援者）や並び順などの細かい設定は管理画面「コミュニティ管理」で行います。

## 主な機能

| 区分 | 内容 |
| :-- | :-- |
| 画面 | Slack と同じ配色・レイアウト（左のナビゲーション「ホーム／DM／アクティビティ」、サイドバー、チャンネル、スレッド）。スマホは下部のタブ |
| チャンネル | 公開／非公開、会員種別・支援者限定、運営のみ投稿（会員はスレッド返信・リアクション可）、自動参加、トピック・説明、スター、アーカイブ |
| ダイレクトメッセージ | 運営⇔会員、会員⇔会員（相手が受付設定をオンにしている場合）。自分用メモ。DM 一覧に最新メッセージを表示 |
| メッセージ | スレッド、リアクション（✅ 👀 🙌 など）、編集・削除、ピン留め、@メンション（運営は @channel）、画像・PDF・Office 文書の添付（10MB まで）、書式（*太字* _斜体_ ~取り消し~ `コード` コードブロック・引用・箇条書き・番号付き）、絵文字だけのメッセージは大きく表示、検索、リンクのコピー |
| アクティビティ | 自分へのメンション・@channel・参加したスレッドへの返信（直近30日）。未確認の件数を表示 |
| リアルタイム | 新着・編集・リアクション・返信数・既読・招待がリロードなしで反映。入力中表示、オンライン表示 |
| 未読・既読 | チャンネルごとの未読数・メンション数、「新規」の区切り、DM の「既読」、チャンネルの「既読 N」 |
| 通知 | 画面内の通知、デスクトップ通知、タイトル・ヘッダー・マイページの未読バッジ。チャンネルごとに「すべて／メンションのみ／ミュート」 |
| 管理 | チャンネル作成・編集・削除、メンバー管理、ユーザー一覧、利用停止、通報の対応、DM 一括送信、最近の投稿の確認 |

## 表示の速さ

- 画面を開いたときに必要なもの（チャンネル一覧・前回開いていたチャンネルのメッセージ・表示名）を、サーバーで1回の問い合わせで取得して最初の表示に含めます（読み込み待ちの表示が出ません）。
- 閲覧権限の判定は1回の問い合わせにつき1回だけ行います（行ごとに判定しない）。メッセージの読み込みも、表示名とまとめて1回で取得します。
- サイドバーでチャンネルにカーソルを合わせると先読みし、未読のあるチャンネルも裏で先読みします。リアクション・スター・参加などはすぐ画面に反映します。
- 画面の一部が変わったときは、その部分だけを描き直します（入力中表示などでメッセージ一覧全体を描き直さない）。

## アイコン・絵文字

- アイコンは Lucide（ISC ライセンス）、絵文字は Microsoft の Fluent Emoji 3D（MIT ライセンス）を使っています。
  Slack 自体のアイコンと Slack が使う絵文字（Apple の絵文字）は著作物で再配布が許可されていないため、同じ雰囲気の自由に使えるものを選んでいます。
- 絵文字の画像は `public/noprecache/emoji/`（ライセンス: `LICENSE-fluentui-emoji.txt`）。PWA の事前キャッシュには含めず、表示したものだけを読み込みます。
  追加するときは `src/lib/emoji.ts` の説明に従ってください（`tests/emojiAssets.test.ts` が確認します）。

## プライバシー・安全

- 他の会員には**コミュニティ用の表示名**だけが表示され、本名は運営だけが確認できます。表示名に「運営」「公式」「Retouch」などは使えません（なりすまし防止）。
- 運営であっても、**他人同士の DM は閲覧できません**。問題のある DM は会員からの通報（本文のスナップショット付き）で確認・削除できます。
- 非公開チャンネルは、メンバーと運営だけが閲覧できます（作成画面にも表示しています）。
- 閲覧権限はデータベースの行レベルセキュリティで判定し、リアルタイム配信・添付ファイル（非公開バケット `community`・署名付き URL）にも同じ権限が適用されます。書き込みはすべて検証付きの関数経由です。
- 操作（チャンネル変更・利用停止・一括送信など）は監査ログに `community.*` として記録されます。

## 制限事項

- 通知はサイト（またはコミュニティ画面）を開いている間に表示されます。スマホのプッシュ通知（アプリを閉じていても届く通知）には対応していません。
- Supabase の Realtime には同時接続数の上限があります（Free プランは 200 接続）。上限に近づいた場合は Supabase のプラン変更を検討してください。
- コミュニティのデータ（チャンネル・メッセージなど）は DB バックアップ（管理画面「DBバックアップ」）に自動的に含まれます。添付ファイル（Storage）は含まれません。
