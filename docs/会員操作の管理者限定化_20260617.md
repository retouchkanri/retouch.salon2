# 会員によるお手続きを「管理者限定」に変更（2026-06-17）

## 背景・ご要望

- 会員（吉川 美知様 / mjdf0615@docomo.ne.jp）より、2口支援 → 1口支援（1口分の削除）のご希望。
- 運営方針として、各種お手続き（追加・変更・削除）は**会員ご自身では行えないようにし、管理者（運営）が管理画面から行う**運用に変更したい、とのご依頼。

## 対応内容（今回の実装）

会員（マイページ）からの **追加・変更・削除（停止）** を一律で停止しました。
ボタン等の導線は非表示にし、万一直接URL／API を叩かれても **サーバ側で 403** を返して二重に防いでいます。

### 対象（会員側で不可 → 管理者のみ）

| 機能 | マイページ表示 | API |
| --- | --- | --- |
| 一口支援（新規申込・口数変更・停止） | ボタン非表示／案内表示 | 403 |
| 会員種別・プラン変更（A/B/C 加入・解約） | 「会員種別を変更」リンク非表示 | 403 |
| 特別チーム会員（申込・停止） | 申込・停止ボタン非表示 | 403 |
| 単発寄付（マイページ内 /mypage/donate） | クイックアクション非表示 | 403 |
| 見学会・個別見学の予約（新規・変更・取消） | 予約ボタン非表示（一覧の閲覧は可） | 403 |
| 馬の面会（申込・取消） | フォーム非表示（履歴の閲覧は可） | 403 |
| 登録情報の編集（氏名・住所・電話など） | 入力欄を閲覧専用に＋案内表示 | 403 |

### 制限の対象外（会員のまま操作可能）

意図的に残しています。「項目の追加・変更・削除」ではなく、アカウント保全・決済手段の管理にあたるためです。

- **メールアドレス／パスワードの変更**（ログイン情報。`/api/mypage/account`）
- **プロフィール写真**（`/api/mypage/avatar`）
- **お支払い方法（カード）の変更** … Stripe カスタマーポータル（`/api/stripe/portal`）。
  - ※ これを止めると、決済失敗時に会員がカードを直せず、かえって運営対応が増えるため残しています。
- **公開ページの単発寄付（`/donate`）** … 非会員も使う寄付導線のため、今回の会員操作制限の対象外です。

> これらも管理者限定にしたい場合は、ご連絡いただければ対象に追加します。

## 切り替え方法（重要）

機能フラグ **`NEXT_PUBLIC_MEMBER_SELF_SERVICE`** で制御します。

- 既定（未設定）… **会員操作はすべて不可（＝今回の運用）**
- `NEXT_PUBLIC_MEMBER_SELF_SERVICE=true` … 従来どおり会員がセルフで操作可能に戻る

※ `NEXT_PUBLIC_` 付きのため、値を変更した場合は **再ビルド（再デプロイ）** が必要です。

## 管理者（運営）側の操作について

管理画面では従来どおり、追加・変更・削除が可能です。今回のご要望（2口 → 1口）も対応できます。

- 管理画面 ＞ 支援（一口支援）一覧 で、対象会員の支援レコードの **口数を「1」に変更**、または **削除** が可能です。

### ⚠️ Stripe（決済）との関係に注意

- **管理画面からの口数変更・削除は、データベース（当サイトの表示・月額）にのみ反映され、Stripe の課金内容は自動では変わりません。**
- そのため、吉川様のケースのように **Stripe 側の定期課金を運営側で調整（解約・金額変更）したうえで**、管理画面で口数を 1 に変更してください（ご連絡いただいた運用＝「Stripeを削除して管理画面で1口に変更」と一致します）。
- 会員側からの操作（マイページ）は Stripe と自動同期していましたが、その経路は今回停止しています。
